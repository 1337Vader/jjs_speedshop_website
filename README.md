# JJ's SpeedShop LLC — Website

A single-page site for JJ's SpeedShop LLC, a performance and general auto repair shop in West Palm Beach, FL (appointment-only).

## Structure
- `index.html` — page markup
- `style.css` — design system (instrument-cluster / dyno-sheet visual identity)
- `script.js` — boost gauge rendering/animation, mobile nav

No build step — plain HTML/CSS/JS. Open `index.html` directly or serve the folder with any static file server.

## Deploying with GitHub Pages
1. Repo Settings → Pages
2. Source: Deploy from branch → `main` → `/ (root)`
3. Save — the site will publish at `https://<username>.github.io/jjs_speedshop_website/`
